# 📊 DotaStatsBot

Бот для Discord, который показывает винрейт и количество игр в **рейтинге** за последние 30 дней.

### 📥 Файлы в Релизах
* **`DotaStatsBot.exe`** — Готовый бот (скачал и запустил).
* **`DotaStatsBot.py`** — Исходный код скрипта.

---

### ⚙️ Инструкция по запуску
1. Запустите файл.
2. Введите **Bot Token** в консоль (запрашивается только 1 раз при первом запуске).
3. Бот сохранит его в файл `config.json` и автоматически выйдет в онлайн.

### 📋 Команды
> `!c <ссылка_на_steam>` — выдает статистику: винрейт, количество игр, победы и поражения.
